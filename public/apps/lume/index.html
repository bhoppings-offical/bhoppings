Why Lume

Built for developers who notice the details.

No runtime dependencies. No icon fonts. Just clean SVG files that work everywhere.

Pixel-perfect grid

Every icon lives on a 24×24 grid with consistent stroke weights and optical alignment across the entire set.

Pure SVG

Infinitely scalable, themeable with CSS currentColor, and zero JavaScript dependencies required.

Two styles

Solid for functional UI clarity. Bold for visual emphasis. Every icon ships in both — pick one or mix as needed.

How to use

npm 
npm install lumicons
CDN 
<link rel="stylesheet" href="https://cdn.lumicons.com/lumicons.css">
HTML 
<i class="lumicon lumicon-home"></i>
React 
import { LumeHome } from 'lumicons/react';

export default function App() {
  return <LumeHome size={24} />;
}
CSS 
.my-icon {
  color: #2BB8DA;
  width: 24px;
  height: 24px;
}

.icon-lg { width: 48px; height: 48px; }

About Lume

Lume is the spiritual successor to Font Awesome Solid, built for how modern teams actually work. Designed by bhop with a focus on clarity and consistency across every glyph in the set.

Every icon ships as a standalone SVG — no icon fonts, no sprite sheets, no runtime. Just clean files you can drop anywhere and theme with a single CSS property.
